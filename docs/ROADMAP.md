# Roadmap

- **Phase 1 – Foundation (done, pending live Supabase verification):** auth, projects CRUD, dashboard, RLS.
- **Phase 2 – AI Script Studio:** OpenAI script and scene generation, scene editor.
- **Phase 3 – Visual Studio:** image/video provider adapters, Pexels stock search, media library.
- **Phase 4 – Voice and Audio:** ElevenLabs voiceovers, music, sound effects.
- **Phase 5 – Video Editor:** timeline (canonical JSON), captions, preview.
- **Phase 6 – Rendering:** Celery/Redis workers, FFmpeg composition, MP4 export, cloud storage.
- **Phase 7 – CapCut:** asset package, SRT, editable-project compatibility testing (no claims until tested).
- **Phase 8 – Production:** deployment, monitoring, security testing, backups, optimisation.
